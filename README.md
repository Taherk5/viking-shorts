# Viking Shorts

Animated history Shorts (cartoon blob style), drawn in code and rendered with Chromium + ffmpeg.
Finished videos are published as GitHub *Releases* so Metricool can fetch them by URL.

- `scenes_short.js` – vertical 1080x1920 scenes · `scenes.js` – 16:9 version
- `audio.py` (music/SFX), `voiceover.py` (Kokoro TTS), `mix.py` (ducking mix)
- `setup.sh` – installs the TTS runtime and downloads the voice model with hash check
- No secrets live in this repo.
